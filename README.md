# Trabalho-Final-Programacao-Concorrente
Repositório voltado à organização do trabalho final da disciplina de Programação Concorrente, realizado pelos alunos: Francisco Guilherme (Frerp), Leonardo Pereira, Davi Alexandrino, Gabriel Farias e André Gondim, alunos de Ciência da Computação da UFCA - Universidade Federal do Cariri. 

O projeto trata do uso de mutex, semáforos e variáveis de condição para gerenciar threads que simulam um tráfego urbano de veículos em um trânsito cheio de cruzamentos. Cada veículo é representado por uma thread, de modo que o trânsito é simulado e controlado por meio do emprego dos conceitos de programação concorrente aprendidos durante a disciplina.
